# Download

Get the print-ready files from the
[latest release](https://github.com/Karneades/Defensomania/releases/tag/deck-latest).
It contains all PDFs and a zip with all PNG files, and it is rebuilt
automatically whenever the cards or the layout change.

## Which file to use

Which file to use depends on how you print.

### Print at home

Use
[`Defensomania-9-cards-per-sheet-all-front-without-bleed.pdf`](https://github.com/Karneades/Defensomania/releases/download/deck-latest/Defensomania-9-cards-per-sheet-all-front-without-bleed.pdf).
It contains
all scenarios and activities with 9 cards per sheet.

### Print at a print shop or a custom card manufacturer

The required files vary between shops:

* Some want PDFs with 1 card per sheet.
* Others want PNG images. Use the PNG zip from the release.

Front and back usually have to be provided separately. Both formats include
the usual 1/8" bleed around the card, which is cut away after printing.

## Build the deck yourself

You can build the card deck yourself using
[Squib](https://github.com/andymeneely/squib). See the
[build instructions](https://github.com/Karneades/Defensomania/blob/master/BUILD.md).
